# Todo App
A React app that displays tasks that need to be completed

## Installation
1. Clone the repository to your local computer:
```bash
    git clone <your-repo-url>
```
2. Move into project folder:
```bash
    cd todo-app
```
3. Install dependencies:
```bash
    npm install
```

## Running the App
1. Starting Server:
```bash
    npm run dev
```
2. Open browser and navigate to:`http://localhost:5173`( or the URL shown in your terminal)
