# Todo App
A React app that will be used to display tasks that need to be completed


## Installation
1. Clone the repository to local computer
2. Install dependencies:
```bash
    npm install
```
3. Start the developer Server:
```bash
    npm run dev
```


## Starting Developer Server
1. Starting Server:
```bash
    npm run dev
```
2. Open browser and navigate to:
[http://localhost:5173](http://localhost:5173)
